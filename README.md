# 💪 FitCoach AI Assistant

FitCoach — це MVP персонального фітнес-асистента, побудованого на базі агентної архітектури за допомогою фреймворку **Agno** та моделі **Google Gemini 3.5 Flash**.

## 🎯 Продуктова мета
Забезпечити аматорів спорту надійним інструментом для швидкого розрахунку фітнес-метрик (ІМТ, цільовий пульс) та підбору безпечних вправ для домашніх тренувань. 

Система створена з фокусом на **безпеку ** та **точність**: агент жорстко обмежений локальною базою знань і не має права надавати медичні рекомендації або генерувати вправи, не перевірені тренерами.

## ⚙️ Архітектура та Технології
*   **LLM:** Google Gemini 3.5 Flash (висока швидкість та економічність).
*   **Оркестрація:** Agno — забезпечує інтеграцію інструментів та управління пам'яттю сесії.
*   **Інтерфейс:** Gradio — веб-інтерфейс для комфортної взаємодії кінцевого користувача.
*   **Tools (Інструменти):**
    *   `exercise_lookup` — семантичний пошук вправ по локальній базі.
    *   `calculate_target_heart_rate` — математичний розрахунок кардіо-зон за формулою Карвонена.
    *   `bmi_calculator` — розрахунок ІМТ із категоризацією за стандартами ВООЗ.

## 🚀 Як запустити
1. Відкрийте файл `Final_Londkevych_2.ipynb` у Google Colab.
2. Додайте ваш `GOOGLE_API_KEY` у розділ Secrets (або введіть вручну при запуску).
3. Запустіть усі комірки (Runtime -> Run all).
4. Перейдіть за згенерованим публічним посиланням Gradio наприкінці зошита.

## 🧪 Тестування (Сценарії)
Бот успішно обробляє як позитивні запити (розрахунок метрик), так і межові (Edge Cases):
*   Відмовляє у призначенні лікування (спрацьовує Guardrail у системному промпті).
*   Відмовляється вигадувати вправи, яких немає в базі (спрацьовує обмеження Tool Calling).
*   Відхиляє запити не за темою (наприклад, про погоду чи кулінарію).
